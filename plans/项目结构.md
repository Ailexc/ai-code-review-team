### 10.3 Makefile

```makefile
# Makefile

.PHONY: help setup dev prod test lint format clean

# 默认目标
help:
	@echo "Available commands:"
	@echo "  make setup      - Setup development environment"
	@echo "  make dev        - Start development environment"
	@echo "  make prod       - Start production environment"
	@echo "  make test       - Run tests"
	@echo "  make lint       - Run linters"
	@echo "  make format     - Format code"
	@echo "  make clean      - Clean up"

# 环境设置
setup:
	python -m venv venv
	source venv/bin/activate && pip install -r requirements.txt
	cd frontend && npm install

# 开发环境
dev:
	docker-compose -f docker-compose.dev.yml up -d

# 生产环境
prod:
	docker-compose -f docker-compose.prod.yml up -d

# 运行测试
test:
	cd backend && pytest
	cd frontend && npm test

# 代码检查
lint:
	cd backend && ruff check . && mypy .
	cd frontend && npm run lint

# 代码格式化
format:
	cd backend && black . && isort .
	cd frontend && npm run format

# 清理
clean:
	docker-compose down -v
	rm -rf backend/__pycache__
	rm -rf frontend/node_modules
	rm -rf frontend/dist
```

## 11. 文件命名规范

### 11.1 Python文件

| 类型 | 命名规范 | 示例 |
|------|----------|------|
| 模块 | 小写下划线 | `project_service.py` |
| 类 | 大驼峰 | `ProjectService` |
| 函数 | 小写下划线 | `get_project_by_id` |
| 常量 | 大写下划线 | `MAX_RETRY_COUNT` |
| 私有 | 单下划线前缀 | `_internal_method` |

### 11.2 TypeScript文件

| 类型 | 命名规范 | 示例 |
|------|----------|------|
| 组件 | 大驼峰 | `ProjectCard.tsx` |
| Hook | 小驼峰，use前缀 | `useProjects.ts` |
| 工具 | 小驼峰 | `formatDate.ts` |
| 类型 | 大驼峰 | `ProjectType.ts` |
| 常量 | 大写下划线 | `API_BASE_URL` |

### 11.3 配置文件

| 类型 | 命名规范 | 示例 |
|------|----------|------|
| 配置 | 小写点分隔 | `docker-compose.yml` |
| 环境 | 小写点分隔 | `.env.example` |
| 脚本 | 小写下划线 | `setup_dev.sh` |
