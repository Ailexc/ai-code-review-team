1. 功能概述

安全审查 Agent 是系统的核心 Agent 之一，负责扫描代码中的安全漏洞和风险。它采用两层分析策略：

  1. 确定性工具层（Semgrep）：使用 200+ 条预置安全规则进行静态扫描，覆盖 OWASP Top 10 常见风险
  2. LLM 语义层：对代码进行深度语义分析，补充静态工具难以发现的逻辑漏洞

3. Semgrep 静态分析

Semgrep 是一个开源的静态分析工具，支持多种语言和规则集。本 Agent 根据项目语言自动选择合适的规则集：

语言规则集说明
Pythonp/python, p/flask, p/django, p/sqlalchemy, p/bandit覆盖 Web 框架、ORM、安全审计
JavaScriptp/javascript, p/nodejs, p/react, p/expressjs覆盖 Node.js、React、Express
TypeScriptp/typescript, p/nodejs, p/react, p/expressjsTypeScript 专用规则
Javap/java, p/springSpring 框架安全规则
Gop/golangGo 语言安全规则

4. LLM 智能分析

LLM 分析层补充 Semgrep 难以发现的逻辑漏洞：

  • SQL 注入：检测动态拼接的 SQL 语句
  • 命令注入：识别 os.system/subprocess 中的用户输入
  • XSS：检测未转义的用户输入输出
  • 硬编码密码：识别代码中的敏感信息
  • 不安全反序列化：pickle/yaml.load 等危险调用
  • eval 使用：动态代码执行风险

7. 实际案例

❌ 不安全代码

import os

def get_user(user_id):
    # SQL 注入风险
    query = f"SELECT * FROM users WHERE id={user_id}"
    
    # 命令注入风险
    os.system(f"echo User {user_id} accessed")
    
    return session.execute(query)

✅ 修复后

import subprocess
from sqlalchemy import text

def get_user(user_id):
    # 使用参数化查询
    query = text("SELECT * FROM users WHERE id=:id")
    
    # 使用 subprocess 避免 shell 注入
    subprocess.run(["echo", f"User {user_id} accessed"], check=True)
    
    return session.execute(query, {"id": user_id})

8. 配置说明

Semgrep 扫描参数：

  • 超时时间：单个规则集 120s，单个文件 30s
  • 文件大小限制：最大 1MB
  • 文件数量限制：最多 50 个文件
💡 提示：如果项目中未安装 Semgrep，Agent 仅执行 LLM 语义分析（确定性工具为空，审查深度下降）。建议在 Docker 环境中预装 Semgrep 以获得最佳效果。
