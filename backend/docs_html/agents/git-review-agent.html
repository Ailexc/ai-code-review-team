1. 功能概述

Git 审查 Agent 分析 Git 仓库的提交规范和分支健康度：

  1. 提交规范：检查是否遵循 Conventional Commits 格式
  2. 分支策略：检查分支命名规范和主分支保护
  3. 贡献统计：分析活跃度、文件热点、提交频率
  4. LLM 点评：对提交消息质量进行语义评价

3. 提交规范检查

检查最近 50 条提交是否遵循 Conventional Commits 规范：

<type>(<scope>): <description>
类型说明示例
feat新功能feat(auth): 添加 OAuth 登录
fix修复fix(api): 修复分页参数校验
docs文档docs: 更新 API 文档
refactor重构refactor(db): 优化查询逻辑
perf性能perf(cache): 添加 Redis 缓存

4. 分支策略分析

检查分支命名是否符合规范：

  • 主分支：main / master / develop
  • 功能分支：feature/description
  • 修复分支：fix/description
  • 发布分支：release/version

5. 贡献统计

分析仓库的贡献数据：

  • 文件热点：哪些文件被修改最频繁
  • 提交频率：按时间统计提交数量
  • 活跃度：最近提交的时间分布

6. LLM 点评

LLM 对提交历史进行语义分析：

  • 提交消息质量：是否清晰描述变更内容
  • 提交粒度：单次提交是否包含过多不相关变更
  • 安全风险：是否有敏感信息泄露（密码、token）
