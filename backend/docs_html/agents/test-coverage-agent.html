1. 功能概述

测试覆盖 Agent 负责识别代码中未被测试覆盖的函数，并生成测试建议：

  1. AST 静态分析：解析源码提取所有函数，与测试文件对比识别未覆盖函数
  2. LLM 测试建议：为关键未测试函数生成测试用例建议

3. AST 静态分析

AST 分析层的工作流程：

  1. 收集测试文件：识别 test_*.py / *_test.py 和 tests/ 目录
  2. 提取测试引用：扫描测试文件中引用的函数名
  3. 提取源码函数：解析所有非测试 Python 文件的函数定义
  4. 对比识别：标记未被任何测试引用的函数
  5. 过滤规则：跳过私有函数（_开头）和测试函数（test_开头）

4. LLM 测试建议

LLM 为未测试函数生成测试建议，覆盖：

  • 正常路径测试：典型输入和预期输出
  • 边界值测试：空值、零值、最大值等边界情况
  • 异常路径测试：错误输入、异常处理等

def calculate_discount(price: float, discount: float) -> float:
    """计算折扣价格"""
    if discount < 0 or discount > 1:
        raise ValueError("折扣必须在 0-1 之间")
    return price * (1 - discount)

def validate_email(email: str) -> bool:
    """验证邮箱格式"""
    import re
    return bool(re.match(r'^[\w.-]+@[\w.-]+\.\w+$', email))
