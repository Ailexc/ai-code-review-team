1. 功能概述

规范审查 Agent 负责检查代码的规范性和可维护性。它结合了 Ruff 的快速静态检查和 LLM 的语义理解能力：

  1. Ruff 静态检查：覆盖 pyflakes、pycodestyle、复杂度等规则，识别可自动修复项
  2. LLM 语义点评：识别命名规范、函数复杂度、重复代码等需要语义理解的问题

3. Ruff 静态检查

Ruff 是一个极快的 Python linter，速度比传统工具快 10-100 倍。本 Agent 使用 Ruff 检查以下规则类别：

规则前缀说明严重度可自动修复
Fpyflakes（未定义名称、未使用 import 等）warning部分
E/Wpycodestyle（格式、空格、行长等）suggestion✅
C复杂度（函数过长、嵌套过深）warning❌
N命名规范（变量/函数/类名）suggestion❌
Iimport 排序nitpick✅
UPpyupgrade（语法升级）suggestion✅
Bflake8-bugbear（常见错误）warning部分

4. LLM 语义点评

LLM 分析层补充 Ruff 难以发现的语义问题：

  • 命名规范：函数/变量名是否清晰、符合语言惯例
  • 函数复杂度：是否过长、嵌套过深、职责单一、参数过多
  • 重复代码：可提取的公共逻辑
  • 类型注解：Python 中缺失的类型标注
  • 可读性：魔法数字、全局变量、死代码等

6. 自动修复能力

Ruff 支持自动修复的规则会标记 is_auto_fixable: true，用户可以在审查详情页一键应用修复：

  • F401：移除未使用的 import
  • F841：移除未使用的变量
  • I001：自动排序 import
  • E/W：格式化修复（空格、缩进等）
  • UP：语法升级（如 f-string 替代 % 格式化）

❌ 不规范代码

import os
import sys
import json  # 未使用

def Calc(x,y):  # 命名不规范（应为 snake_case）
    result=x+y  # 缺少空格
    return result

def process_data(data, flag, verbose, timeout, retries):  # 参数过多
    pass

✅ 修复后

import os
import sys

def calc(x: int, y: int) -> int:  # 命名规范 + 类型注解
    result = x + y  # 格式修复
    return result

def process_data(
    data: list,
    flag: bool = False,
    verbose: bool = False,
    timeout: int = 30,
    retries: int = 3,
) -> None:  # 参数分组 + 默认值
    pass
