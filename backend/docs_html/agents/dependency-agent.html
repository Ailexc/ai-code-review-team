1. 功能概述

依赖审查 Agent 负责检测项目依赖中的已知漏洞和过时版本。它支持 Python 和 JavaScript 两种生态系统：

  1. Python 依赖：使用 pip-audit 查询 PyPI/OSV 漏洞库
  2. JavaScript 依赖：查询 npm registry 检测过时版本
  3. LLM 风险点评：分析依赖清单，识别风险/弃用/许可证问题

3. Python 依赖审计

使用 pip-audit 扫描 Python 项目的依赖漏洞：

  • 支持的清单文件：requirements.txt、pyproject.toml、setup.py、Pipfile
  • 漏洞库：PyPI + OSV（Open Source Vulnerabilities）
  • 输出：CVE ID、漏洞描述、修复版本
CVSS 评分严重度说明
≥ 9.0critical严重漏洞，需立即修复
≥ 7.0warning高危漏洞，建议尽快修复
≥ 4.0suggestion中低危漏洞，择机修复

4. npm 过时检测

查询 npm registry 检测 JavaScript 项目的过时依赖：

  • 检测方式：异步并发查询（Semaphore=5 限制并发数）
  • 比较逻辑：声明版本 vs 最新稳定版
  • 超时控制：单个包 15s 超时

5. LLM 风险点评

LLM 分析层补充工具难以发现的依赖风险：

  • 已知漏洞历史：旧版 django/flask/requests/lodash/axios 等
  • 过时或未维护：长期未更新的包
  • 冗余或冲突：功能重复的依赖
  • 版本约束缺失：未固定版本的包
  • 许可证风险：不安全的许可证或来源不明的包

6. 检测规则详解

规则 ID检测项严重度说明
PIP-AUDIT-*CVE 漏洞按 CVSS 评分pip-audit 发现的已知漏洞
NPM-OUTDATED过时依赖warning版本落后于最新稳定版
LLM-DEPLLM 风险分析suggestionLLM 发现的依赖风险

7. 实际案例

❌ 有问题的依赖

# requirements.txt
django==2.2.0        # 已停止维护，存在多个 CVE
requests==2.20.0     # 存在安全漏洞
flask==1.0           # 版本过旧

# package.json
{
  "dependencies": {
    "lodash": "4.17.15",  # 存在原型污染漏洞
    "axios": "0.21.0"     # 存在 SSRF 漏洞
  }
}

✅ 修复后

# requirements.txt
django>=4.2,<5.0     # LTS 版本，持续维护
requests>=2.31.0     # 最新稳定版
flask>=3.0           # 最新稳定版

# package.json
{
  "dependencies": {
    "lodash": "4.17.21",  # 最新安全版本
    "axios": "1.6.0"      # 最新稳定版
  }
}
