⚡ 性能分析 Agent

功能概述

通过 AST 静态分析 + LLM 语义分析，检测 Python 代码中的性能反模式和瓶颈。

检测维度

规则 ID检测项严重度说明
PERF-N+1N+1 查询critical循环内 ORM 调用，应改为批量查询
PERF-SYNC同步阻塞criticalasync 函数内 time.sleep/requests 等阻塞调用
PERF-CONCAT字符串拼接warning循环内字符串 += 拼接，O(n²) 复杂度
PERF-UNBOUNDED无限制查询suggestion.all() 无 .limit() 限制返回数量

代码示例

❌ N+1 查询（循环内 ORM 调用）

def get_users(session, user_ids):
    results = []
    for uid in user_ids:
        user = session.query(User).filter(User.id == uid).first()  # 每次循环都查一次 DB
        results.append(user)
    return results

✅ 修复后（批量查询）

def get_users(session, user_ids):
    return session.query(User).filter(User.id.in_(user_ids)).all()  # 一次查询

❌ 同步阻塞（async 函数内）

import time

async def fetch_data():
    time.sleep(5)  # 阻塞事件循环！
    return "done"

✅ 修复后（使用 asyncio.sleep）

import asyncio

async def fetch_data():
    await asyncio.sleep(5)  # 非阻塞
    return "done"

技术实现

  • 使用 Python AST 模块解析源代码，遍历 AST 节点检测反模式
  • AST 检测确保零误报（确定性分析）
  • LLM 补充检测 AST 无法发现的复杂性能问题
