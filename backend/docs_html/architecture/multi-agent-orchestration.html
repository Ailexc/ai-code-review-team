1. 设计理念

多 Agent 并行编排是本系统的核心架构模式，核心思想是：

  • 职责分离：每个 Agent 聚焦一个审查维度（安全/规范/依赖/测试/性能/Git）
  • 并行执行：使用 asyncio.gather 并行启动所有 Agent，最小化审查时间
  • 独立上下文：每个 Agent 独立分析，互不干扰
  • 结果聚合：所有 Agent 完成后统一去重、排序、评分

3. 并行执行机制

使用 Python asyncio 实现真正的并行执行：

# 并行启动所有 Agent
tasks = [
    agent.analyze(project_path, file_paths)
    for agent in agents
]
results = await asyncio.gather(*tasks, return_exceptions=True)

关键特性：

  • 真正的并行：所有 Agent 同时启动，不是串行等待
  • 异常隔离：单个 Agent 失败不影响其他 Agent
  • 超时控制：每个 Agent 有独立的超时设置

4. 结果聚合

所有 Agent 完成后，进行统一的结果聚合：

  1. 去重：按 (rule_id, file_path, line_start) 去重
  2. 排序：按严重度排序（critical > warning > suggestion）
  3. 评分：基于 findings 的负分制评分（0-100）

5. ReviewFlow 编排

除了直接编排，系统还支持 CrewAI Flows 编排模式：

        ...

        # 聚合结果

6. 代码示例

综合审查的完整流程：

# 1. 创建所有 Agent
agents = [
    SecurityAgent(),
    CodeStyleAgent(),
    DependencyAgent(),
    TestCoverageAgent(),
    PerformanceAgent(),
    GitReviewAgent(),
]

# 2. 并行执行
tasks = [agent.analyze(path) for agent in agents]
results = await asyncio.gather(*tasks)

# 3. 聚合结果
all_findings = []
for agent, findings in zip(agents, results):
    for f in findings:
        f["agent_name"] = agent.name
    all_findings.extend(findings)

# 4. 去重 + 排序
unique = deduplicate(all_findings)
sorted_findings = sort_by_severity(unique)

# 5. 计算健康度
health_score = calculate_health(sorted_findings)
