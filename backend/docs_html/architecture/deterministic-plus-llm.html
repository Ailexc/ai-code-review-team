1. 设计理念

本系统采用确定性工具兜底 + LLM 语义补充的混合模式：

  • 确定性工具：Semgrep/Ruff/pip-audit/AST 确保基础检测不漏，零误报，可解释
  • LLM 补充：语义理解和复杂场景分析，补充静态工具的盲区

3. 确定性工具层

工具用途特点
Semgrep安全漏洞扫描200+ 预置规则
Ruff代码规范检查极快速度，支持自动修复
pip-audit依赖漏洞扫描PyPI/OSV 漏洞库
AST性能反模式检测N+1、同步阻塞等
GitPythonGit 规范检查提交规范、分支策略

4. LLM 语义层

LLM 补充确定性工具的盲区：

  • 逻辑漏洞：SQL 注入、命令注入等需要语义理解的问题
  • 命名规范：函数/变量名是否清晰、符合语言惯例
  • 风险评估：依赖包的风险等级和升级建议
  • 修复建议：针对具体问题的修复方案

5. 模式优势

优势说明
零误报兜底确定性工具确保基础检测不漏
语义补充LLM 发现静态工具难以检测的逻辑问题
可解释性确定性工具的结果可追溯、可解释
成本控制确定性工具快速便宜，LLM 仅补充复杂场景

6. 实际案例

# 第一层：Semgrep → 发现 3 个安全问题
semgrep_results = semgrep.scan(["p/python", "p/flask"])
# 第二层：LLM → 发现 1 个逻辑漏洞
llm_results = await llm.analyze(code)
# 聚合：3 + 1 = 4 个安全问题
all_findings = semgrep_results + llm_results
