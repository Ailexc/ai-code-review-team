🌐 系统架构总览

1. 项目定位

构建一个多 Agent 协作代码审查系统，模拟真实 Code Review 流程。用户提交代码，系统触发多个专业 Agent 并行审查，由主 Agent 汇总生成结构化审查报告。

2. 核心设计原则

  • 确定性工具兜底 + LLM 语义补充：Semgrep/Ruff/pip-audit/AST 确保基础检测不漏，LLM 补充语义理解和修复建议
  • 6 Agent 并行编排：asyncio.gather 并行执行，结果去重聚合，最小化审查时间
  • 可验证维度：每个 Agent 聚焦可验证的代码质量维度（安全/规范/依赖/覆盖/性能/Git）

4. 数据流

  1. 触发：用户通过 Web UI 选择项目和审查类型
  2. 调度：ReviewService 解析审查类型，确定需要运行的 Agent 列表
  3. 并行执行：asyncio.gather 并行启动所有 Agent
  4. 结果聚合：每个 Agent 的 findings 汇总、去重、按严重度排序
  5. 健康度计算：基于 findings 的负分制评分（0-100）
  6. 报告生成：Markdown + HTML 格式报告
