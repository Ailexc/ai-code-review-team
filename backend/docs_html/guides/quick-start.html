🚀 快速开始

Step 1: 注册项目

  1. 点击侧边栏「项目管理」
  2. 点击「添加项目」按钮
  3. 填写项目名称、路径（本地代码目录的绝对路径）、选择语言
  4. 点击确认，项目创建成功

Step 2: 选择审查能力

  1. 点击侧边栏「触发审查」进入审查能力中心
  2. 你会看到 7 个审查能力卡片，每个卡片展示了：
    • 工具链：使用什么工具分析代码
    • 检测维度：会检查哪些问题
    • 预计耗时：大概需要多长时间
  3. 点击感兴趣的卡片，展开详情区域

Step 3: 触发审查

  1. 在展开的详情区域中，选择项目
  2. 选择触发方式：
    • 扫描目录：扫描项目中的代码文件
    • 粘贴代码：直接粘贴代码片段
    • 上传文件：上传代码文件或压缩包
  3. 点击「开始审查」按钮
  4. 通过 WebSocket 实时查看审查进度

Step 4: 查看结果

  1. 审查完成后自动跳转到审查详情页
  2. 查看问题列表（按严重度排序）
  3. 点击问题可查看代码片段和修复建议
  4. 点击「HTML报告」查看完整报告
  5. 点击「下载报告」导出 Markdown 格式报告

Step 5: 自动修复（可选）

  1. 在审查详情页点击「自动修复」按钮
  2. 系统会列出可自动修复的问题
  3. 点击「预览补丁」查看修复内容
  4. 确认无误后点击「应用修复」

💡 提示

  • 「综合审查」会并行运行全部 6 个 Agent，一次性发现所有维度的问题
  • 你可以在「仪表盘」查看系统整体状态和健康度趋势
  • 每个 Finding 可以标记为「已确认」或「已解决」，便于跟踪
