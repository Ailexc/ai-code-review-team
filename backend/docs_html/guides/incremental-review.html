1. 功能概述

增量审查专注于 Git diff 场景，只审查变更的代码：

  1. 语义 Diff：AST 级结构化变更识别（函数/类级别）
  2. 影响分析：变更影响哪些调用方
  3. 意图分析：LLM 分析变更目的和风险

2. 语义 Diff

AST 级 Diff 识别函数/类级别的变更：

变更类型说明风险
新增新增函数/类低
修改修改现有函数/类中
删除删除函数/类高

3. 影响分析

  • 直接调用方：哪些函数调用了变更的函数
  • 间接影响：调用方的调用方（传递影响）
  • 风险分级：根据影响范围评估风险等级

4. 使用流程

  1. 选择要审查的 Git 项目
  2. 指定 base 和 head commit
  3. 系统自动进行语义 Diff 分析
  4. 查看结构化变更和影响分析

5. 实际案例

# Git diff 显示修改了 get_user 函数
- def get_user(user_id):
-     return session.query(User).filter(User.id == user_id).first()
+ def get_user(user_id):
+     return session.query(User).filter(User.id == user_id).first() or None
