1. 功能概述

AutoFix 自动修复引擎消费审查发现中的 is_auto_fixable 标记，生成修复补丁：

  1. Ruff 自动修复：import 排序、格式化、简单 lint（确定性，直接改文件）
  2. LLM 辅助修复：复杂代码问题的智能补丁（需人工确认）

3. Ruff 自动修复

规则修复内容
F401移除未使用的 import
F841移除未使用的变量
I001自动排序 import
E/W格式化修复
UP语法升级

4. 使用流程

  1. 在审查详情页查看 findings
  2. 点击「自动修复」按钮
  3. 系统列出可自动修复的问题
  4. 点击「预览补丁」查看修复内容的 diff
  5. 确认后点击「应用修复」

5. 实际案例
